# Retired workflow assets

These skill directories are preserved for historical reference and direct legacy regression tests.
They are outside the manifest skill discovery root and are not part of the installed runtime inventory.
Do not follow their phase, dispatch, result-action, or hook instructions for new execution.

The supported entrypoint is `$moondex:execute`; shared code resolves through `runtime/moondex-runtime.py`.
Historical approvals do not authorize a new run. Existing docs/sdd and approval records retain their original meaning.

`design-md` and `enhance-prompt` are retired Stitch-specific skills. Their original instructions are preserved here for history, outside discovery.
