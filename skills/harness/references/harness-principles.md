# 환경 점검 관점

프로젝트 작업을 실제로 가능하게 만드는지 확인하는 참고 항목이다. 필수 문서 형식이나 단계가 아니다.

- 지침 탐색: AGENTS.md에서 관련 기준과 실행 명령을 찾을 수 있는가?
- 기준 보존: 합의 내용과 사후 결과가 분리되고 변경 승인을 추적할 수 있는가?
- 검증 가능성: 테스트가 실제 사용자 행동과 중요 실패 조건을 검출하는가?
- 의존성 경계: 아키텍처 규칙이 필요한 곳에 명시되고 실제 위반 검사가 있는가?
- 실행 관찰: 긴 실행, 실패, 중단과 개입 대기를 구분할 증거가 있는가?
- 재현성: 필요한 입력과 환경을 다시 구성할 수 있고 숨은 전역 설정에 의존하지 않는가?
- 유지보수: 중복되거나 오래된 지침을 줄이되 사용자 기록과 승인 기준을 보존하는가?

필요한 부분만 개선한다. 정책 승격이나 자가개선은 별도 사용자 요청에 따른다.
